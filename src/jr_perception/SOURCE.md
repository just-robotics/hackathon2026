# Происхождение детектора

Основа — `feature/detector`, включённая в main commit 67f7ae5.
Сохранены новый фон из карты, дополнительные маркеры и инструменты AMCL/FAST-LIO2.
Поверх перенесены согласованные изменения feature/egor-detector-fix:

- Минимум 12 точек обода. Недостаточная поддержка не создаёт слабое измерение.
- Центры кандидатов и выходных треков проверяются по исходным occupied-клеткам
  `/map` (>=50), без инфляции. Unknown/outside не считаются стеной.
- Видимость проверяется по точкам обода; для прогнозного трека — по передней
  поверхности корпуса. Требуется минимум 50% видимых точек, запас у конца
  луча 8 см. Закрытая линия до центра сама по себе не запрещает видимый корпус.
- Истёкшие треки удаляются до ассоциации. Для повторного выбора нужны три
  последовательные сильные детекции; память старого места действует 1,5 с.
  Свежая цель удерживается, слабые фрагменты не поддерживают её бесконечно.

В реальном FAST-LIO2-стеке вход — `/sensing/lidar/points_filtered` и
`/localization/fastlio/odometry`; источником FAST-LIO2 остаются raw облако и IMU.
`opponent/odom` содержит выбранный трек; markers, robot_markers и box_markers
сохраняют разделение новой версии main. Детектор не обновляет costmap.
Профили real/simulation и bag AMCL/FAST-LIO2 содержат согласованные параметры.

Старая реализация исправлений проверялась на трёх реальных bags; это не
доказательство текущей интеграции с обновлённым main и FAST-LIO2.
После текущего переноса проверки не выполнялись по указанию пользователя.
Дальнейшие изменения распознавания и трекера требуют согласования.


03.10.2026 по согласованию перенесена проверка граней plane_test/rectangle_fit
из main 191d477, без box_tracker и linefit. Прямой порог 1.5 даёт 0 выбранных
треков на четырёх реальных bags. Поэтому plane_ratio=0 в модели и профилях:
функция оставлена для экспериментов, активное поведение не изменено.
Результаты: results/detector-plane-20261003/report.md. Проверено на записанной
позе AMCL через PoseRelay, работоспособность FAST-LIO2 этим не подтверждена.


После дополнительного согласования проверка адаптирована: сравнение только
по одному ободу после удаления выбросов, plane_ratio=.8, преимущество RMS
>=1.5см, видимый угол >=90°. Короткий видимый обод не получает дополнительного
запрета. Адаптация активна в профилях real/simulation и AMCL/FAST-LIO bag.
На 4 реальных bags выдача2478→2477, слабые кандидаты1644→1394, длинные паузы
не выросли. Нет разметки: это не precision/recall и не доказательство FAST-LIO2.
Отчёт: results/detector-plane-adapted-20261003/report.md. BoxTracker/linefit
не перенесены. Прямой исходный вариант1.5 выше остаётся отвергнутым.
