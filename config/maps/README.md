# Статическая карта maze_bag_v1

Построена из `/home/eddyswens/ROS/hsl2026Extra/maze_bag_v1`:
1408 Livox облаков,28163 IMU,140.81с; нет odom/TF.

- `maze_bag_v1.yaml` + `maze_bag_v1.pgm` — Nav2 static map.
- `maze_bag_v1.png` — сама сетка без траектории.
- `maze_bag_v1_preview.png` — сетка с восстановленной траекторией.
- `maze_bag_v1_quality.json` — параметры, допущения и фактические проверки.
- `maze_bag_v1_processing.yaml` — использованные параметры FAST-LIO2.

Resolution0.05м;74×96 клеток;origin[-0.50,-0.65,0].
Основные стены выровнены коррекцией yaw+1,8° до растеризации; тот же
поворот применён к PCD/траектории и сохранён в raw_to_map_rotation. Чёрный — занято,
белый — наблюдаемое свободное, серый — неизвестно. Мелкие разрывы/неизвестные
участки не дорисовывались. Дальний фон отсечён по bounding box крупнейшего
наблюдаемого компонента стен +0.25м; все клетки внутри сохранены.

Система map: начальные оси установленного перевёрнутого LiDAR, с коррекцией
наклона по наблюдаемому полу; XY-ноль перенесён к начальной позиции LiDAR.
Точная привязка базы к sensor origin по этой записи не проверяется:
TF/конфигов сессии нет, размещение подтверждено пользователем приблизительно.
Поэтому стартовые позы роботов и arena_bounds надо задать в этой системе;
старые симуляционные стартовые координаты к ней автоматически не относятся.

На перекрывающихся ранних/поздних наблюдениях стен median NN residual1.49см,
p90=5.32см при отсечении0.15м; overlap80.3%. Это согласованность наблюдений,
не ошибка относительно эталона или доказанный drift. Робот закончил примерно
в0.415м от начала, но запись не гарантирует точного возврата: это не метрика
ошибки замыкания. Backend не выполняет loop closure. Физическая локализация
по сохранённой карте пока не проверена.

Карта фактически загружена Humble Nav2 map_server:482 occupied,4837 free,
1785 unknown, frame map. Формат и направление PGM подтверждены.

Для подключения в real.yaml:

```yaml
map_file: maps/maze_bag_v1.yaml
arena_bounds: [-0.50, -0.65, 3.20, 4.15]
```

Карта включена в real.yaml с AMCL внутри start_real; миссия real_match.yaml.
Задайте реальные robot.start/opponent.start в map. Начальный yaw для положения
начала записи после выравнивания —0,031416рад. Точное положение базы нужно
уточнить (в RViz через 2D Pose Estimate), поскольку TF записи отсутствует.
Одометрия остаётся /odom, AMCL выдаёт /amcl_pose и map→odom; navigation/self
получает исправленное положение для decision/planner/MPPI.
Физическая локализация остаётся непроверенной; см. docs/REAL_ROBOT.md.

3D-облако и полная траектория после выравнивания:
`results/real-bag-check-maze-v1/map-aligned/maze.pcd` и `trajectory.csv`.
Диагностика, registered scans и промежуточные полные карты находятся в том же
results/ каталоге и не коммитятся. Повтор обработки — docs/OFFLINE_MAPPING.md.
