## Подтверждено и ограничения

Все60 парных gate-аудитов до старта/частичного старта/после финиша прошли; у каждой стороны один final cmd_vel publisher. Все20 private runtime очищены. Сборка/хэши исходников одинаковы, отчёты двух ролей относятся к одному run ID. Нет сценарного патруля/телепортов.

Порог0.2 подтверждён для40 индивидуальных отчётов.0.3 пока не подтверждён в каждом матче: исследователь seed8=0.297. Положение/скорость соперника оцениваются по LiDAR; truth используется referee и offline анализом. Результат относится к одному конфигу стартов и этому лабиринту. GUI, другой лабиринт и аппаратная переносимость этой серией не проверены.

Страж слабее по частоте выполнения задачи. Найдены default pursuer_speed0.3 при собственном cap0.5 и краткие остановки из-за одноточечного PURSUE reference (seeds0/1). Исправления требуют отдельного цикла, не смешивались с оценкой. Высотный фильтр уже проверялся высоким ящиком отдельно; низкое неизвестное препятствие0.15м ещё не проверено. Задача целиком не завершена.
